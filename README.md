# 一天怎么过

她自己的作息表 + 28 天菜单（84 顿），一个 HTML 文件，没有第三方依赖。

## 页面结构

1. **首屏「现在」**：现在几点 / 接下来是什么 / 这顿吃什么，加早·午·晚三个圆点（点一下记「这顿吃过了」）
2. **一天**：24 小时色带（点色块跳到那个时段）+ 时间轴，右上角可切「游泳日 / 非游泳日」两套作息
   - 游泳日：19:00–21:30 游泳，21:35 收尾，22:00 学习 60 min
   - 非游泳日：19:00–21:20 深度学习 140 min，21:20–22:30 自由休闲，22:30–22:50 快速复盘，22:50 上床
3. **今天吃什么**：按 28 天食谱里「今天」那一行取菜（星期几 → 对应那天的早/午/晚），可前后翻日
4. **28 天食谱**：四周表格全部展开，今天那一行有底色 + 「今天」标签；表格右上角「跳到今天」

打卡记录存在浏览器 `localStorage`（键 `nov-eaten-v1`），只在这台设备上，不上传、不同步。
深色模式跟随系统；打印时隐藏交互控件、四周表格全部展开。

## 隐私

页面里是完整作息（起床、通勤、游泳、关灯时间）。默认不该公开可访问，三种做法任选：

1. **仓库设为 private**（Pages 会自动下线，最彻底）；
2. 只发本地文件给她，保存在手机里；
3. 用页面自带的口令门（弱防护）：
   - 打开 `index.html#h=你的口令`，把弹出的哈希填进 `index.html` 里的 `GATE.hash`；
   - 把同一行上方的 `GATE.on` 改成 `true`；
   - 口令门是前端校验，看源码能绕过，要真正保密只能走 1。

已加 `<meta name="robots" content="noindex,nofollow">`，避免被搜索引擎收录。

## 部署

`index.html` 放仓库根目录，Settings → Pages 选 `main` / 根目录；或直接双击本地打开。

## 数据

菜单在 `<script id="data" type="application/json">` 里。

映射规则：28 天为一个周期，周期从周一开始，**2026-11-02（周一）是第 1 周第 1 天**。
所以 2026-10-26 那一周是周期里的第 4 周（10-30 落在「第 4 周 · 周五」），
11-01 周日仍是第 4 周，到 11-02 周一才回到第 1 周。
`posInCycle(date)` 算第几周，`planFor(date)` 取当天那一行。
