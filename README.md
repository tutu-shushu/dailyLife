# 一天怎么过 · 作息 × 四周食谱

单人份的一个月食谱，加上一天的时间轴。一个 HTML 文件，无需构建、无第三方依赖。

## 用法

1. 把 `index.html` 放进仓库根目录；
2. 仓库 Settings → Pages → Source 选 `main` / 根目录；
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

也可以直接双击 `index.html` 离线打开。

## 页面内容

- **一天的时间分布**：06:30–23:30 按真实时长比例上色的色带，点任意色块跳到对应时段；
- **一天的时间轴**：16 个节点，每行标时长；右上角可在「游泳日 / 非游泳日」之间切换，三餐卡片随之更换；
- **四周菜单**：28 天 × 3 餐 = 84 顿，四个周标签切换；点格子打卡，环形进度条实时更新；
- 顶部进度条、滚动淡入、悬停眨眼、打卡涟漪、周完成彩带；`prefers-reduced-motion` 下自动关闭动画。

## 数据

- 打卡记录存在浏览器 `localStorage`（键：`nov-week-v1`、`nov-day-v1`），不上传、换设备不同步。
- 菜单文字内嵌在 `index.html` 的 `<script id="data" type="application/json">` 里，改菜名直接搜那段 JSON。
- 打印：浏览器 Ctrl/Cmd+P 会隐藏交互控件，四周表格全部展开，适合直接出 A4。

自用。
